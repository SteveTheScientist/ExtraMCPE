# Documentation Index & Start Here Guide

## "Start Here" Order for Beginners
1. [project-map.md](project-map.md) - Learn the directory layout, main game loops, and basic cookbook examples.
2. [modding-blocks.md](modding-blocks.md) - Learn how to add new blocks, textures, shapes, and world properties.
3. [modding-items.md](modding-items.md) - Learn how to add items, foods, tools, weapons, crafting recipes, and translations.
4. [mobs-and-world.md](mobs-and-world.md) - Learn how to create custom mobs, biomes, world generation features, and sky settings.
5. [gui-and-player.md](gui-and-player.md) - Understand the Screen GUI component hierarchy, player skins, capes, and model rendering.
6. [android-bridge.md](android-bridge.md) - Explore the AppPlatform abstraction and JNI bridge between C++ and Android Java.
7. [skin-report.md](skin-report.md) - Short technical analysis report on player skin loading, models, and platform image decoders.
8. [git-and-build.md](git-and-build.md) - Build system instructions (CMake, Android, iOS, Web, CI workflows) and build error troubleshooting.
9. [CLOUDS.md](CLOUDS.md) - Detailed architecture of volumetric 3D cloud rendering and options.
10. [FONT.md](FONT.md) - Text rendering, font formatting, and text input box component architecture.
11. [termux-server.md](termux-server.md) - Guide for hosting a dedicated Minecraft PE server on an Android phone using Termux.

## Documentation File Summaries
* **[README.md](README.md):** Main documentation index.
* **[termux-server.md](termux-server.md):** Detailed beginner guide for compiling and hosting a dedicated server on an Android phone using Termux.

* **[modding-blocks.md](modding-blocks.md):** Step-by-step beginner guide to adding custom blocks, 3D shapes, terrain atlas textures, and properties.
* **[modding-items.md](modding-items.md):** Beginner guide to adding custom items, food, tools, armor tiers, crafting/smelting recipes, and translations.
* **[mobs-and-world.md](mobs-and-world.md):** Guide to creating custom mobs, renderers, biomes, world generation features, day/night cycles, and fog settings.

* **[CLOUDS.md](CLOUDS.md):** Deep-dive guide into cloud alpha fading, height calculations, and rendering geometry.
* **[FONT.md](FONT.md):** Deep-dive guide into text formatting, section sign color codes, string width measurements, and text input controls.
