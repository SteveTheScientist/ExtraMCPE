# Documentation Index & Start Here Guide

## "Start Here" Order for Beginners
1. [docs/project-map.md](docs/project-map.md) - Learn the directory layout, main game loops, and basic cookbook examples.
2. [docs/modding-blocks.md](docs/modding-blocks.md) - Learn how to add new blocks, textures, shapes, and world properties.
3. [docs/modding-items.md](docs/modding-items.md) - Learn how to add items, foods, tools, weapons, crafting recipes, and translations.
4. [docs/mobs-and-world.md](docs/mobs-and-world.md) - Learn how to create custom mobs, biomes, world generation features, and sky settings.
5. [docs/gui-and-player.md](docs/gui-and-player.md) - Understand the Screen GUI component hierarchy, player skins, capes, and model rendering.
6. [docs/android-bridge.md](docs/android-bridge.md) - Explore the AppPlatform abstraction and JNI bridge between C++ and Android Java.
7. [docs/skin-report.md](docs/skin-report.md) - Short technical analysis report on player skin loading, models, and platform image decoders.
8. [docs/git-and-build.md](docs/git-and-build.md) - Build system instructions (CMake, Android, iOS, Web, CI workflows) and build error troubleshooting.
9. [docs/CLOUDS.md](docs/CLOUDS.md) - Detailed architecture of volumetric 3D cloud rendering and options.
10. [docs/FONT.md](docs/FONT.md) - Text rendering, font formatting, and text input box component architecture.

## Documentation File Summaries
* **[README.md](README.md):** Main documentation index and recommended reading order for new developers.
* **[project-map.md](docs/project-map.md):** High-level folder map, platform main loops, per-frame tick/render lifecycle, and "how-to" cookbook examples.
* **[android-bridge.md](docs/android-bridge.md):** Full `AppPlatform` virtual interface, JNI method lookup catalog, control flows, and Android platform integration.
* **[gui-and-player.md](docs/gui-and-player.md):** `Screen`, `Button`, and `TextBox` APIs, player skin/cape rendering pipeline, and immediate model refreshing.
* **[skin-report.md](docs/skin-report.md):** Technical investigation report answering questions on skin loading, outer layers, capes, and platform image loaders.
* **[modding-blocks.md](docs/modding-blocks.md):** Step-by-step beginner guide to adding custom blocks, 3D shapes, terrain atlas textures, and properties.
* **[modding-items.md](docs/modding-items.md):** Beginner guide to adding custom items, food, tools, armor tiers, crafting/smelting recipes, and translations.
* **[mobs-and-world.md](docs/mobs-and-world.md):** Guide to creating custom mobs, renderers, biomes, world generation features, day/night cycles, and fog settings.
* **[git-and-build.md](docs/git-and-build.md):** Multi-platform build guide (CMake, Android NDK, Xcode), GitHub Actions workflow descriptions, and build failure troubleshooting.
* **[CLOUDS.md](docs/CLOUDS.md):** Deep-dive guide into cloud alpha fading, height calculations, and rendering geometry.
* **[FONT.md](docs/FONT.md):** Deep-dive guide into text formatting, section sign color codes, string width measurements, and text input controls.
